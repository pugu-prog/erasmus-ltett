# Erasmus+ Schülerinfo (LTEtt)

Infoseite und Stand für das Erasmus+-Auslandspraktikum in Portugal, Schuljahr 2026/2027.

- `index.html` – die Seite (GitHub Pages)
- `downloads/` – Aufgabenblätter (PDF, base64-kodiert, werden von der Seite beim Klick entpackt)
- `apps-script/Code.gs` – Google-Skript für die Tabelle „Erasmus+ Stand 2026-27 (Lehrer)“

Die Schülerdaten liegen nicht in diesem Repository, sondern in der Google-Tabelle.
Schüler lesen nur; Lehrer haken mit dem Lehrer-Code ab.

## Neues Schuljahr
Neue Tabelle anlegen (gleiche Spalten), Skript einfügen und bereitstellen, die neue Web-App-URL in `index.html` bei `API_URL` eintragen.
